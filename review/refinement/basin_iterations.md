# 北盆地壓力站逐輪 Prompt

圖在 `basin_rounds/B0` 至 `B19`。每組的 `basin_ground.png` 和 `basin_overhead.png` 是 Godot 4.7.2 Forward+ Vulkan 實際輸出，使用 RTX 4080 筆電和 1120 × 630。測試相機近景座標 (2.1, 3.12, 6.8) 看向 (0, 1.1, −4.5)，FOV 58°。俯視從 (0.25, 15.9, 15.0) 看向 (0.32, 0.1, −1.0)，FOV 52°。
