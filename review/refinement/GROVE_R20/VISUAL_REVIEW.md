## 實際改善

- 原薄片葉冠換成曲面葉卡、枝冠法線與高度明暗；秋金和冷綠分組仍在，時鐘及通路可辨。
- 6,755 叢原創地被，包含三處較高較深的草群核心（291 叢），按區域分批；主路與水域留空。數量只用於重現，不是品質評分。
- 地表與草根共用低頻色場；壓低草尖偏白、分出低矮露地。後續仍要改善部分草帶重複性。
- grove 專用石材降低貼圖顆粒和微法線；未更改其他場景共用 painted_stone。
- 水色改為較清楚藍綠；末輪去掉整池規則蛇形亮紋，改為較弱、局部淺岸碎光。
- 天光與日照色調重設，霧從近景退後，使用近乎中性的陰影調色體積與克制高光泛光。

## 失敗與回退

| 候選 | 發現 | 處置 |
|---|---|---|
| A | 山體成巨大多面球、水平腰帶，樹冠成分離球團 | 山體回退連續原形；樹冠接合與壓扁 |
| B | 冠層過度平塗，草尖偏白均一 | 明確傳遞枝冠世界法線、恢復高度冷暖；草群分核心與空隙 |
| C | 葉冠、石材改善，但池中規則蛇形亮線很假 | D 改為局部不規則低對比焦散 |
| D | 雙鏡位保留，通行回歸通過 | 可接續，不作發布金標準 |

## 仍有差距

背景大山仍偏圓鼓，缺少更有節奏的山肩與寬轉面；前岸花帶仍過長、整齊；部分岸邊草帶仍欠自然疏密。水色較乾淨，但近岸深度與材質反射仍需多時段再校準。
獨立複評看過基準及 A/B/C，同意 C 的樹冠、石材改善，指出水紋問題；D 由主代理重新渲染核對水紋移除。
