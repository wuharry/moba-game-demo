# 從逐輪 Prompt 找到的共同關鍵點

四張原創場景用同一份分項表評閱。近景與俯視各計 100 分，分項為地形 20、材質 20、資產品質 20、擺景 15、光影與水 15、可讀性 10。每項用 0 至 5 級描述灰模到接近參考圖的完成度，再按權重換算。四肢動作與手機效能不在這份美術分數內。現行驗收門檻是每個鏡位 90 分。

## 兩種風格都有效的做法

| 關鍵做法 | 是什麼問題讓 Prompt 改寫 | 實際對照 |
| --- | --- | --- |
| 先看剪影，再上材質。地形要有大中小，植被要有能區分的主枝方向與冠形。 | 同一個飽和度套在十幾棵圓樹上仍然會看到同形重複。單顆岩柱再多也很難形成連續的河谷。 | 北盆地 B11 連續崖；日藤 SV5 三種冠形、SV7 錯峰山體；雨庭 R04 枝幹和樹冠重做、R06 山稜。 |
| 把地標接到周圍地形與用途。先做出中尺度的落腳、擋土、管路或集水構件。 | 大地標周圍撒滿小東西仍會像擺模型。北盆地 B10 的淺色疊圓盤多了一個強焦點，卻沒交代設施功能。 | 北盆地 B12、B16 有入水閘、台座與管路；潮鎖 R05 的低檢修平台；雨庭 R07 集水時計加入軸座、固定件和接水結構。 |
| 只在接觸界面加變化。水岸、潮線、耗損和根部由場景本身的地面與水深資料決定。 | 直線岸邊與全場同樣密的泡沫，會讓水面像一張貼紙。道路補片的硬輪廓會破壞大塊面。 | 潮鎖 R06 依實際岸線調海面並融合鋪面；北盆地 B17 換成地面磨耗遮罩；雨庭 R05 用地形高度與薄濕緣控制池水；日藤 SV6 增加岸石、池階和低護牆。 |
| 控制會搶焦的亮度和形狀，並讓近景與俯視各自看得清。 | 白草、亮圓盤和整條發光水渠在近景就突兀，到俯視更容易變成大色塊。相反地，近景看不見的遠山拼接，俯視很容易暴露。 | 北盆地 B10／B15／B17；日藤 SV7 先發現俯視露縫再修；潮鎖 R07 岩壁遮擋與海面鋸齒，以 R08 回退重做。 |
| 保存失敗圖，用同一個鏡位看一項改動。 | shader 出白料仍可能成功寫圖。只看完成訊息或換一個好看的相機都會掩蓋問題。 | 北盆地 B17 修正 shader 同名，再以相同 FOV 重畫。潮鎖 R07保留失敗圖，R08 只保留已確認有益的低矮岩層。 |

## 兩種風格各自控制什麼

- **手繪日照系**。樹、石與水面保留不同燈光反應。遠坡先分成上方純剪影與下方有色層，再以岸石和樹群連到主路。日藤保留開闊的庭院。雨庭用集水階地和橙綠樹冠框住步道。
- **冷濕遺跡系**。結構有清楚的作用與潮痕。光色主要用在通電設備與流程節點。中遠岩層沿水的流向塑形。壓力站讓岩谷和壓力調節器相接，潮鎖讓維修岸與控制水閘相接。

## 11 月 24 日再次驗證的做法

- **先從俯視定岸形，再在近景調反光。** 潮鎖 R09–R10 的潮間岩棚讓淺水區有形狀。雨庭 R08 的反光消失太多，R09 只在短落水線補回亮度。北盆地 B20 把流痕放到浸水岩下游，避免每段水面同亮。
- **中型設備要在固定鏡位看得到它的用途。** 日藤 SV8 左坡雖有分水器，入口鏡位被植物擋住。SV9 移了落位和高差後，從兩個鏡位都讀到台地和引水關係。
- **把過於整齊的行走邊界拆成有空隙的組塊。** 北盆地 B21 細長灰岩容易在俯視成為一條邊。B22 以兩組半埋矮岩、碎石和植物回接地面。
- **用較弱的鏡位決定下一輪。** 北盆地近景 77 分維持，俯視由 75 到 78。把兩個分數分開記錄，較容易選對要修的結構。

## 達標版本帶回主 Prompt 的做法

| 關鍵點 | 迭代證據 |
| --- | --- |
| 大、中尺度先形成場地的用途，再整理細節。 | 北盆地 B23 的絞盤棚讓中景有用途，但岩面破縫與空白谷底限制俯視。B24 岩岸、閘門與蓄水輪廓接合後，俯視到 85。日藤 SV11 的果園階地和岔路先改善俯視，SV12 再補地面雕刻、岸邊和光影。 |
| 光、水和標記集中在真正的轉場。 | 北盆地 B26 壓暗引導燈，讓分岔標記與主地標各自可讀。潮鎖 R16 讓鋪面標線沿真實走測路線轉彎，兩張近景都由 83 到 85。日藤 SV12 的枝葉落影與淺水紋放在入口和岸腳附近，雙鏡位各 88。 |
| 岸的輪廓、水深和局部波紋沿著同一份地形。 | 雨庭 R11 增加岩塊後俯視仍是 80。R12 以實體池岬打開水岸變化到 83。R15 成列亮波與時計爭焦，R16 改為沿階口衰減的短波，雙鏡達 85／86。 |

## 提高到 90 分後確認的共同做法

| 關鍵點 | 迭代證據 |
| --- | --- |
| 從兩個角度檢查大型形體的落腳和轉接。 | 日藤 SV13 近景 92、俯視 88，遠山和谷底有硬接縫。SV14 讓岩台依實際坡度延伸並接上谷底，俯視到 92。雨庭 R17 的遠丘、低岩層和水岸階地各有功能，兩個鏡位都看得到高差。 |
| 把著色錯誤的原因和美術取捨逐輪找出來。 | 雨庭的切片色塊在停用陰影與固定透明度時仍出現，改取樣雜湊後消失。R18 再以成群的低矮岸植和局部落影補近景，近景從 89 到 92。 |
| 冷濕場景的設備、池槽和步道在俯視要能連成用途。 | 潮鎖 R21 從閘門、回水槽到池沿依實際標高建出高差，廊道接進崖腳檢修間。北盆地 B33 讓薄瀑沿岩腳分流，控制箱接向絞盤和開敞台。 |
| 手繪自然場景把開闊草坡與林冠整理成明確的色塊，再留局部高彩給入口與岸邊。 | 日藤 SV15 的中遠處以低反差草坡和同向風吹的樹草帶出開闊感，暖色集中於近果園。雨庭 R19 讓冷綠林冠與暖斜陽形成前後層，少量琥珀葉色留在水岸和轉折。 |
