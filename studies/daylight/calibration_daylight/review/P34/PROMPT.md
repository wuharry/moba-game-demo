# P34-D 中段草群與前層林島

由核對雜湊的 P33-B 原包接續。在 Windows RTX 4080 Laptop／Godot 4.7.2 Compatibility 先重拍原固定主景、斜角岩壁及三時段 MOBA。保持鏡位、曝光、地形、碰撞、兩條運鏡及 N 材質開關。

四組不等寬草群延伸右中坡與左岩腳，寬葉核心、低邊緣和裸地共存；兩組灌木接岩腳。三組前林維持高核心、低邊緣及群間谷口。

## 迭代

- A 草區偏後、主鏡變化小。以原相機射線找出目標地表位置，沒有移動相機。
- B 草群位置和高低可讀，但核心太亮、太密，像細針乾草。不採作最終版。
- C 僅改新增草：寬葉比例提升到 92%，高度上限 1.85 降至 1.58、葉寬增加，群心略減密。新草尖 RGB 乘數為 0.85／0.88／0.94；根部維持原地色。
- D 修正亂數連動：保留率及種型/朝向抽樣恢復 P33，在已抽出的植株上局部改高寬、種型及疏密；新增灌木用複製的獨立 RNG 狀態，維持後續花群位置。D 為最終實拍候選。

## 程式範圍

foliage.gd：四組草區、兩組灌木；background.gd：87 株前層林群；grass.gdshader：只對標記新草尖降低亮黃；daylight.gd：版本字串。Shader light()、地形、碰撞、相機、軌道及全部光照參數維持 P33。
